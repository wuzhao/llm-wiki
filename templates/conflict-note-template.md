# 冲突保留片段模板

用于 `ingest`、`lint`、`query` 发现冲突时的标准记录格式。

```markdown
> ⚠️ 注意：以下内容存在观点冲突，暂不做删旧保新。

### 观点 A

- 结论：<一句话结论>
- 来源：<source 页面或外部资源>
- 时间：<YYYY-MM-DD 或 unknown>

### 观点 B

- 结论：<一句话结论>
- 来源：<source 页面或外部资源>
- 时间：<YYYY-MM-DD 或 unknown>

### 当前处理

- 状态：并存
- 原因：证据尚不足以单向裁决
- 后续：等待新增来源或复核
- 复核时间：<YYYY-MM-DD 或待定>
```
