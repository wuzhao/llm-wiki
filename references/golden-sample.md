# Golden Sample 回归基线

本文件定义 LLM Wiki 的最小可运行示例，用于版本升级后的快速回归。

## 目标

- 用最小输入覆盖 `init`、`ingest`、`synthesize`、`query`、`lint`、`explore` 六个 `workflow`
- 验证「`preflight` 硬校验 + `report-only` 默认 + `append-only` 日志 + 冲突保留」是否仍生效
- 提供可重复的通过标准，避免只靠主观判断

## 基线输入

场景 1：本地 Markdown 素材

- 输入：一篇本地技术笔记
- 预期：首次摄入生成 1 个 raw 页面，并建立或补充对应来源摘要；相同内容重复输入提醒已摄入并核对既有摘要
- 预期：修改原始本地文件后运行 `lint`，报告「🟡 中等」的原始文件变更提醒

场景 2：URL 素材

- 输入：1 个可访问 URL
- 预期：成功抓取并生成 raw/source；若抓取失败，明确报错并要求粘贴正文，且不写空文件

场景 3：粘贴文本素材

- 输入：一段带术语的纯文本
- 预期：检查核心实体、概念及相关历史摘要，按实际信息增量补充知识；满足建页门槛时当次新建 entity/concept，信息不足时保留候选及原因

场景 4：冲突素材

- 输入：两段对同一主题结论相反的内容
- 预期：保留冲突双方，不执行删旧保新

场景 5：`lint` 巡检

- 输入：对上述结果运行 `lint`
- 预期：默认仅报告；仅在显式 `--fix` 时执行安全修复，不做级联删除

场景 6：raw 元数据补齐与正文只读

- 输入：缺少 `type` 或 `title`、带来源地址与采集时间的 raw 页面，正文包含有唯一同名候选的失效链接与多行代码
- 预期：显式 `lint --fix` 仅补齐可确定的元数据，保留来源字段与未知字段，正文的链接、空白和换行逐字节不变；正文链接问题仍在报告中

场景 7：写后检查

- 输入：本次写入的 wiki 页面包含指向不存在页面的链接，另有不相关页面的历史问题
- 预期：`--lint-files <本次变更与受影响页面> --fail-on error` 返回 1 且不改文件，index 始终检查；Agent 核对修正本次问题后重查返回 0，再追加完成日志

场景 8：工作区技能与知识库分离

- 输入：技能安装在工作区局部目录，目标知识库在独立目录；路径含空格与中文，终端当前目录切换到另一个已初始化的知识库
- 预期：使用已确定解释器、技能脚本与目标知识库的绝对路径，摄入和修复只写目标知识库；搜索与影响分析读取正确目标，技能及另一个知识库均不改变
- 预期：缺少依赖时，报错指向实际运行的解释器和技能内的依赖文件，不能引导 Agent 在当前知识库目录查找同名依赖文件

场景 9：单篇充分与顺带提及

- 输入：一份只顺带提及术语的素材，以及一份对某工具提供用途、行为和限制的完整说明
- 预期：前者不创建占位页；有后续提炼价值时记录候选、原因和触发条件。后者无需等待更多来源或用户点名，当次建立实体页及有实质内容的概念页，保留来源

场景 10：跨篇补足与同义更新

- 输入：首次素材仅说明术语与对象的关系，后续素材提供其定义、机制或适用条件，并使用别名
- 预期：后续摄入检索历史摘要与暂缓候选，补足后建页，移除已处理候选；已有同义页面时更新它，不重复创建。跨篇页面说明关联、差异或条件，不只是拼接摘要

场景 11：首次历史回扫与中断恢复

- 输入：超过单批阅读量的旧摘要，缺少提炼状态，实体和概念目录为空
- 预期：立即触发历史回扫，分批阅读与记录；新进程只列出本轮未完成摘要。全部检查、来源链完整且写后检查通过后，检查点附在同一条事务日志中。未完成时不写检查点，不把剩余摘要当作已处理

场景 12：周期、去重与版本

- 输入：在已完成回扫后摄入重复素材、同文转载、仅修改导航，以及达到配置周期的不同来源正文或同一来源的不同正文版本
- 预期：前三者不推进周期；有效正文变化累计后触发下一轮，摘要只引用最新版也不遗漏中间版本。数量只触发检查，不能强制产出页面或把多个版本当作独立证据

场景 13：记录异常与覆盖缺口

- 输入：候选缺少暂缓原因、检查指纹失效、目录读取失败或来源链无法到达 raw
- 预期：状态格式错误由工具和 lint 报告，内容变化进入待检查；工具不写文件、不生成完成检查点。`lint --fix` 不补造检查记录、不创建知识页；旧摘要没有状态不作为结构错误

场景 14：显式整理与只读边界

- 输入：未到周期时请求整理已有摘要；另行执行普通 query/explore
- 预期：整理使用 `synthesis_wiki.py --force` 并分批续扫，无需等待周期；普通查询和探索保持只读，不隐式维护知识页

场景 15：统一摄入入口

- 输入：通过 ingest 首次摄入素材，修改同一来源后再次摄入，再提供相同输入；另提供同标题但不同正文的粘贴文本，以及指定既有 `source_id` 的文本更新
- 预期：同一工具分别执行首次保存、版本追加和重复复用，保留历史 raw。来源正文变化必须执行影响分析与更新协议，重复输入仍需补完上次未完成的摘要、提炼或传播；新事务统一记录为 ingest
- 预期：同标题不自动合并来源，文本显式身份建立版本关系；同文不同出处保存来源但不冒充独立证据。重新摄入或重新投喂均执行 ingest，由实际变化决定动作，不强制新增版本或改写历史日志

## 通过标准

- `preflight` 缺失关键结构时立即停止写入
- 每个产生文件变更的 workflow 事务追加一条汇总日志到 `wiki/logs/YYYYMM.md`（当月文件）
- 所有新增或改写的概念页 `frontmatter` 可 YAML 解析且 `type` 非空；根 index 只包含 `okf_version`
- `lint --fix` 不删除 source/entity/concept 页面，不清理历史日志
- 出现冲突时，页面包含冲突标注和来源
- raw 元数据补齐保留来源信息与正文；所有写入 wiki 的业务 workflow 在完成日志前执行只读写后检查
- 主题检查有可恢复记录；满足门槛时生成或维护知识页，证据不足时有明确暂缓原因，不以每批产出数量作为通过条件
- 回扫周期与阅读批次读取 schema；只完成局部检查时不生成全库完成检查点

## 发布前最小回归清单

- 第 1 步：执行自动化回归：`PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v`。
- 第 2 步：执行需要 Agent 语义参与的场景 2、场景 3、场景 4、场景 9 和场景 10，并结合自动化覆盖核对场景 11 至场景 15。
- 第 3 步：核对「通过标准」每一项是否满足。
- 第 4 步：将结果写入迁移记录或发布说明，注明失败项与处理结论。

## 自动化覆盖

- 提炼工具只读，覆盖首次历史回扫、跨进程恢复、显式提前回扫、检查点完成与去重、周期触发、连续版本、候选恢复，以及记录或来源链异常时不生成检查点。建页质量由 Agent 场景验证，脚本不冒充语义判断。

- 摄入只写入 `raw/`，且不接受 `--raw-dir`。
- 输入源参数互斥，含冒号标题仍生成可解析 YAML。
- 技能与知识库使用独立目录；含空格与中文路径、切换到其他知识库目录时，各工具仍使用显式目标与技能内置资源，依赖缺失诊断给出正确位置。
- 链接按完整路径识别，同名多候选不自动猜测。
- 目录遍历失败显式报告覆盖不足；搜索不将零命中宣称为完整结果，lint 返回运行失败且整次安全修复不写入或追加日志。
- 链接修复只在原链接意图指向的目录范围内选择候选，不跨素材正文、`raw/assets/` 附件与 wiki 猜测；嵌套附件目录单独归属，不重复扫描。
- 初始化模板渲染出的空知识库可通过 lint，不产生示例死链。
- raw 使用独立 frontmatter profile，不要求 wiki 的 `description` 与 `tags`。
- 新摄入的来源地址只写 `resource`；旧 `source_url` 可继续识别同一 URL，重复输入不改历史文件，新旧字段版本仍保持依赖传播。两字段冲突由 lint 报告，不自动覆盖或删除。
- raw 即使显式 `--fix` 也不改写正文；元数据补齐保留来源地址、采集时间、未知字段及正文原有换行。
- index、自链接和系统页不掩盖孤儿页。
- 标题锚点、未解决冲突和陈旧页面进入 lint 报告。
- `lint --fix` 在日志不存在时创建当月日志并追加记录。
- 局部 lint 读取全库入链及已有索引，不重复加条目。
- 按文件执行写后检查时，发现本次断链返回失败，人工核对修正后重查通过；检查不落盘，且始终覆盖 index。
- 文件检查范围与目录参数互斥，越界、不存在、不属于 raw/wiki 或位于 `raw/assets/` 的文件在任何写入前被拒绝。
- 初始化只创建 raw 与 wiki 两个顶层内容目录，附件写入 `raw/assets/`；Markdown 附件不参与素材版本识别或 lint 修复，仍可被页面链接引用。
- 网页代码保留缩进和空行，普通表格保留单元格关系，复杂表格保留 HTML；原始响应及指纹可回查。
- 同一来源相同内容重复摄入返回既有路径；来源变更后只有最新快照检查当前源文件，历史正文指纹仍校验。
- 来源链缺失、循环、无效逐条引用、数值未定位候选及归档依赖变化进入只读报告；影响清单包含传递依赖。
- 全文搜索覆盖正文、元数据与别名，支持分页继续读取并保持只读；读取错误显式报告。
- 同次 lint 复用文档读取结果；搜索会话跨批复用候选，显式刷新后才反映资料变化。
- 脚注定义缺失或重复、索引重复条目、错误分区与统计不一致进入只读报告；完整短页无需扩写，可选关系小节可省略。
- 引用式索引链接按正文使用位置归类与判重；共享定义的目标只安全替换一次，保留引用语法和标题。
- 历史日志、YAML 异常页和代码示例不被自动修复；当前日志只追加。
- 当月日志指向外部的符号链接会在任何页面写入前阻断修复。
- 空正文、错误参数、缺失结构及 URL 失败不产生素材或目录变更。
- URL 编码、HTML 段落与列表、非文本响应和响应大小限制使用本地 HTTP 服务或受控响应回归。
- 并发摄入保留所有版本；原子替换失败时保留原文件；重复修复仅追加当次日志。
- `sources[].resource` 的本地路径与锚点单独检查，不掩盖孤儿页。
- 日志追加失败时返回失败并报告已写入页面，不宣称完整成功。
